# 🛡️ SepiPanel

پنل مدیریت **چندپروتکلی VPN** در یک فایل پایتون؛ با نصب تک‌خطی، رابط وب فارسی، مدیریت کاربر، حجم و انقضا، لینک اشتراک (Subscription) و API برای ربات و سایت فروش.

## ✨ امکانات

- نصب و راه‌اندازی با **یک دستور**
- رابط وب فارسی، بدون نیاز به Node.js یا Docker (فقط Python + Flask + SQLite)
- ساخت **اینباند** (WireGuard، AmneziaWG، OpenVPN، L2TP/IPsec، VLESS، Shadowsocks، Trojan)
- **کلاینت** با حجم، تاریخ انقضا، آمار ترافیک، وضعیت آنلاین و غیرفعال‌سازی خودکار هنگام اتمام حجم/زمان
- یک کلاینت می‌تواند عضو **چند اینباند** باشد
- **لینک اشتراک** برای هر کاربر (base64 / raw / conf / json / صفحهٔ وب با QR Code)
- **چند ادمین** با سقف حجم و تاریخ انقضا برای هر کدام (مناسب فروشندگان)
- **API Key** و مستندات داخلی API برای اتصال به ربات تلگرام یا سایت
- **مدیریت نود** (سرور دوم) از طریق SSH برای اینباندهای Xray
- ساخت تانل **BackPack** بین سرورها
- Reality: تولید خودکار کلید و بررسی dest (TLS 1.3 / h2)
- امنیت پنل: **مسیر مخفی**، محدودکردن به IP، HTTPS، تغییر پورت
- بکاپ و بازیابی دیتابیس، فعال‌سازی BBR، آپدیت از داخل پنل
- منوی مدیریت در ترمینال با دستور `sepipanel`

## 🔌 پروتکل‌های پشتیبانی‌شده

| پروتکل | توضیح |
|---|---|
| WireGuard | اینترفیس‌های `wg0`، `wg1` و … با تنظیمات کامل |
| AmneziaWG | وایرگارد مبهم‌سازی‌شده (ضد DPI)؛ نیازمند نصب با `AWG=1` |
| OpenVPN | نصب خودکار هنگام ساخت اینباند، یا با `OVPN=1` |
| L2TP/IPsec | با xl2tpd و strongSwan؛ نصب با `L2TP=1` یا خودکار |
| VLESS | بر پایهٔ Xray-core؛ پشتیبانی از Reality / TLS / none |
| Shadowsocks | بر پایهٔ Xray-core |
| Trojan | بر پایهٔ Xray-core |

> Xray-core اگر از قبل نصب نباشد، هنگام ساخت اولین اینباند Xray خودکار دانلود می‌شود.

## 📋 پیش‌نیازها

- سرور **Ubuntu** یا **Debian** (دسترسی root)
- معماری x86_64 یا ARM64 (برای Xray: armv7 هم پشتیبانی می‌شود)
- یک IP عمومی و باز بودن پورت پنل (پیش‌فرض `8080`)
- برای SSL: یک دامنه که به سرور اشاره کند و پورت 80 آزاد باشد

## 🚀 نصب سریع

با کاربر root اجرا کنید (`sudo -i`):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/iwasSepi/sepipanel/main/install.sh)
```

در پایان نصب، آدرس پنل، نام کاربری و رمز نمایش داده می‌شود. **همان لحظه یادداشتش کنید.**

### نصب با پروتکل‌های اضافه

```bash
# AmneziaWG + Xray + OpenVPN + L2TP
AWG=1 XRAY=1 OVPN=1 L2TP=1 bash <(curl -fsSL https://raw.githubusercontent.com/iwasSepi/sepipanel/main/install.sh)

# پورت دلخواه برای پنل
PORT=9090 bash <(curl -fsSL https://raw.githubusercontent.com/iwasSepi/sepipanel/main/install.sh)
```

### نصب دستی (بدون اسکریپت)

```bash
apt update && apt install -y wireguard wireguard-tools iptables iproute2 python3 python3-pip python3-flask python3-qrcode python3-paramiko curl certbot
mkdir -p /opt/sepipanel && cd /opt/sepipanel
curl -fsSL https://raw.githubusercontent.com/iwasSepi/sepipanel/main/sepipanel.py -o sepipanel.py
python3 sepipanel.py
```

## ⚙️ متغیرهای نصب

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `8080` | پورت پنل (در آپدیت، پورت قبلی حفظ می‌شود مگر اینکه خودتان بدهید) |
| `AWG` | `0` | با `1` شدن، AmneziaWG نصب می‌شود |
| `XRAY` | `0` | با `1` شدن، Xray-core نصب می‌شود |
| `OVPN` | `0` | با `1` شدن، OpenVPN نصب می‌شود |
| `L2TP` | `0` | با `1` شدن، xl2tpd و strongSwan نصب می‌شود |
| `REPO` | `iwasSepi/sepipanel` | ریپوی گیت‌هاب برای دانلود فایل‌ها |
| `BRANCH` | `main` | شاخهٔ ریپو |

## 🔑 بعد از نصب

1. آدرس نمایش‌داده‌شده را در مرورگر باز کنید. مثال: `http://IP:8080/مسیر-مخفی`
2. با نام کاربری و رمز نمایش‌داده‌شده وارد شوید.
3. از تب **تنظیمات** رمز را تغییر دهید.
4. یک اینباند بسازید، سپس کلاینت اضافه کنید و لینک اشتراک را برای کاربر بفرستید.

نصب‌کننده به‌صورت پیش‌فرض:

- یک **رمز تصادفی ۱۶ کاراکتری** می‌سازد
- یک **مسیر مخفی تصادفی** برای پنل تنظیم می‌کند
- سرویس **systemd** با نام `sepipanel` می‌سازد (اجرای خودکار بعد از ریبوت)
- اگر `ufw` فعال باشد، پورت پنل را باز می‌کند

اطلاعات ورود را هر زمان با این دستور ببینید:

```bash
sepipanel info
```

## 🖥️ منوی مدیریت ترمینال

فقط بنویسید:

```bash
sepipanel
```

| گزینه | کار |
|---|---|
| 1 | نمایش اطلاعات پنل (آدرس / ورود / پورت) |
| 2 | تغییر نام کاربری / رمز |
| 3 | تغییر پورت پنل |
| 4 | دامنه و SSL (Let's Encrypt، گواهی دستی، غیرفعال‌کردن HTTPS، تمدید) |
| 5 | مسیر مخفی پنل |
| 6 | محدودکردن دسترسی پنل به IP مشخص |
| 7 | ریست تنظیمات امنیتی (اگر قفل شدید) |
| 8 – 12 | شروع، توقف، ری‌استارت، وضعیت سرویس، لاگ زنده |
| 13 – 14 | بکاپ و بازیابی دیتابیس |
| 15 | فعال‌سازی BBR |
| 16 | باز کردن پورت در فایروال (ufw) |
| 17 | آپدیت پنل |
| 18 | حذف پنل |

### دستورهای سریع

```bash
sepipanel info       # اطلاعات ورود
sepipanel start      # شروع
sepipanel stop       # توقف
sepipanel restart    # ری‌استارت
sepipanel status     # وضعیت
sepipanel log        # لاگ زنده
sepipanel backup     # بکاپ دیتابیس
sepipanel reset      # ریست تنظیمات امنیتی
sepipanel update     # آپدیت
sepipanel uninstall  # حذف
```

## 🧩 مفاهیم پنل (اینباند، کلاینت، ادمین، نود)

**اینباند (Inbound):** یک سرویس VPN روی یک پورت. مثلاً یک اینترفیس WireGuard یا یک اینباند VLESS+Reality. تمام تنظیمات (پورت، DNS، MTU، NAT، کلید، Reality، رمزنگاری و …) روی اینباند تعریف می‌شود.

**کلاینت (Client):** یک کاربر نهایی با حجم، انقضا و توکن اشتراک مخصوص خودش. یک کلاینت می‌تواند روی چند اینباند باشد و در هر کدام آی‌پی/کانفیگ جدا بگیرد. گزینه‌های پشتیبانی‌شده شامل حجم، تاریخ انقضا، ریست خودکار ترافیک (روزانه / هفتگی / ماهانه) و حداکثر کاربر هم‌زمان است.

**ادمین (Admin):** حساب فروشنده/زیرمجموعه با سقف حجم و تاریخ انقضا مخصوص خودش؛ فقط کلاینت‌های خودش را می‌بیند.

**نود (Node):** یک سرور دوم که از طریق SSH به پنل متصل می‌شود تا اینباندهای Xray روی آن اجرا شوند.

**تانل (BackPack):** ساخت تانل بین دو سرور از داخل پنل.

---

## 🔗 لینک اشتراک (Subscription)

هر کلاینت یک توکن دارد و لینک‌های زیر برایش ساخته می‌شود:

| آدرس | خروجی |
|---|---|
| `/sub/<token>` | لینک اشتراک اصلی (صفحهٔ وب با QR یا base64 برای اپ‌ها) |
| `/sub/<token>/<id>.conf` | فایل کانفیگ WireGuard یک اینباند |
| `/sub/<token>/<id>.ovpn` | فایل کانفیگ OpenVPN یک اینباند |
| `/sub/<token>/<id>.svg` | QR Code یک اینباند |
| `/sub/<token>/link.svg` | QR Code لینک اشتراک |
| `/sub/<token>/custom` | ساب کاستوم (برای اینباندهای Xray که فعال کرده باشید) |

> لینک‌های `/sub/` مشمول محدودیت IP و مسیر مخفی پنل نیستند و برای کاربران باز می‌مانند.

## 🤖 API برای ربات و سایت فروش

از تب **API** در پنل یک کلید بسازید (با پیشوند `sp_`). مستندات کامل و زنده در آدرس `/api/docs` پنل در دسترس است.

```bash
curl -H "Authorization: Bearer sp_XXXXXXXX" https://panel.example.com/api/v1/me
```

یا با هدر `X-API-Key: sp_XXXXXXXX`.

### ساخت کلاینت

```bash
curl -X POST https://panel.example.com/api/v1/clients \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"name": "tg12345-1001", "limit_gb": 30, "days": 30, "inbounds": [1, 2], "external_id": "1001", "note": "tg:12345"}'
```

| فیلد | توضیح |
|---|---|
| `name` | نام کلاینت (الزامی) |
| `inbounds` | لیست id اینباندها (الزامی) |
| `limit_gb` | حجم به گیگابایت؛ ۰ = نامحدود |
| `days` | اعتبار به روز؛ ۰ = بدون انقضا |
| `external_id` | شناسهٔ سفارش شما (جلوگیری از ساخت تکراری) |
| `note` | یادداشت دلخواه |
| `reset_period` | `daily` / `weekly` / `monthly` |
| `max_users` | حداکثر کاربر هم‌زمان |
| `count` | تعداد کلاینت (حداکثر ۲۰۰) |

### مسیرهای اصلی

| متد | مسیر | کار |
|---|---|---|
| GET | `/api/v1/me` | اطلاعات و مصرف کلید |
| GET | `/api/v1/inbounds` | لیست اینباندها |
| GET | `/api/v1/clients` | لیست کلاینت‌ها |
| GET | `/api/v1/clients/{id}` | اطلاعات یک کلاینت |
| POST | `/api/v1/clients` | ساخت کلاینت |
| POST | `/api/v1/clients/{id}/renew` | تمدید / تغییر حجم و زمان |
| POST | `/api/v1/clients/{id}/enable` | فعال‌سازی |
| POST | `/api/v1/clients/{id}/disable` | غیرفعال‌سازی |
| POST | `/api/v1/clients/{id}/reset-traffic` | ریست ترافیک |
| POST | `/api/v1/clients/{id}/reset-token` | تعویض توکن اشتراک |
| DELETE | `/api/v1/clients/{id}` | حذف |

## 🌐 دامنه و SSL

### روش ۱: از منوی ترمینال (پیشنهادی)

```bash
sepipanel
# گزینهٔ 4 → گزینهٔ 1
```

دامنه را وارد کنید (باید به IP سرور اشاره کند و پورت 80 آزاد باشد) و ایمیل بدهید؛ گواهی Let's Encrypt گرفته و روی پنل فعال می‌شود.

### روش ۲: گواهی شخصی

```bash
sepipanel   # گزینهٔ 4 → گزینهٔ 4
```

مسیر `fullchain.pem` و `privkey.pem` را بدهید.

### تمدید گواهی

```bash
sepipanel   # گزینهٔ 4 → گزینهٔ 6
```

## 🔥 فایروال و پورت‌ها

پنل فقط پورت خودش را در `ufw` باز می‌کند. پورت اینباندها را باید خودتان باز کنید (در `ufw` یا پنل هاستینگ):

| سرویس | پورت |
|---|---|
| پنل | TCP روی پورت پنل (پیش‌فرض 8080) |
| WireGuard / AmneziaWG | UDP روی پورت اینباند |
| L2TP/IPsec | UDP 500 و 4500 (و 1701) |
| OpenVPN | پورت و پروتکل اینباند (UDP یا TCP) |
| VLESS / Shadowsocks / Trojan | پورت اینباند |

برای باز کردن سریع: `sepipanel` ← گزینهٔ 16.

## 💾 بکاپ و بازیابی

```bash
sepipanel backup
```

بکاپ‌ها در `/root/sepipanel-backups/` ذخیره می‌شوند. برای بازیابی از منو گزینهٔ 14 را بزنید.

> برای انتقال به سرور جدید: بکاپ را بگیرید، پنل را روی سرور جدید نصب کنید، سپس فایل بکاپ را از منو Restore کنید.

## 🔄 آپدیت

```bash
sepipanel update
```

یا همان دستور نصب را دوباره اجرا کنید. **دیتابیس، رمز و پورت حفظ می‌شود.** پنل همچنین وجود نسخهٔ جدید را از طریق Releases گیت‌هاب بررسی می‌کند.

## 🗑️ حذف

```bash
sepipanel uninstall
```

سرویس و دستور `sepipanel` پاک می‌شود اما پوشهٔ `/opt/sepipanel` (شامل دیتابیس) و کانفیگ‌های VPN دست‌نخورده می‌ماند. حذف کامل:

```bash
rm -rf /opt/sepipanel
```
